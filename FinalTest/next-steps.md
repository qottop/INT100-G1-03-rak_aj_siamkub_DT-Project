# Final Test — What To Do Next

## 1. สิ่งที่ Test ต้องตอบ

Prototype ถูกสร้างขึ้นเพื่อช่วยผู้ใช้เช็กข้อมูลก่อนเข้าสวนธนบุรีรมย์ โดยมี People Density, Parking, Recommended Time, Water Station และ Map เป็นส่วนสำคัญ

จากการทดสอบจริง ทีมควรตรวจสอบว่า:

1. ผู้ใช้หา People Density และ Recommended Time ได้เองหรือไม่
2. ผู้ใช้เข้าใจข้อมูล Parking และความหมายของ Capacity/ช่องว่างหรือไม่
3. ผู้ใช้สามารถใช้ข้อมูลเพื่อตัดสินใจเรื่องเวลาได้หรือไม่
4. ผู้ใช้เห็นประโยชน์ของ Map หรือไม่
5. ข้อมูลใดมีความสำคัญต่อการตัดสินใจจริง
6. มีข้อมูลใดที่ผู้ใช้คาดหวังแต่ Prototype ยังไม่มี
7. มีส่วนใดที่ผู้ใช้ไม่เข้าใจหรือไม่ได้ใช้

## 2. Decision rules หลัง Test

### ถ้าผู้ใช้หา People Density / Recommended Time ไม่เจอ
**Mode ถัดไป: Prototype**

- ปรับ Information Architecture
- ทำให้ CTA สำหรับ “เช็กสถานะ” เด่นขึ้น
- ลดข้อมูลที่ไม่จำเป็นบนหน้าแรก
- ทดสอบ Prototype รอบใหม่

### ถ้าผู้ใช้เห็นข้อมูล แต่ไม่เข้าใจความหมาย
**Mode ถัดไป: Prototype → Test**

- เปลี่ยนคำศัพท์ให้เป็นภาษาที่ผู้ใช้เข้าใจ
- เพิ่มคำอธิบายสั้น ๆ
- ทดสอบว่าผู้ใช้ตีความข้อมูลถูกต้องหรือไม่

### ถ้าผู้ใช้ต้องการข้อมูล Real-time มากกว่าข้อมูลจำลอง
**Mode ถัดไป: Define → Prototype**

- กลับไปตรวจว่า Need ที่แท้จริงคือ “ข้อมูล Real-time” หรือ “ความมั่นใจก่อนเดินทาง”
- หาก Need เปลี่ยน ให้พิจารณาแก้ POV/HMW
- จากนั้นออกแบบ Prototype ที่สื่อเรื่อง data freshness อย่างชัดเจน

### ถ้า Parking เป็นปัญหาหลักที่เกิดซ้ำ
**Mode ถัดไป: Prototype → Test**

- ขยายรายละเอียด Parking
- ทดลอง flow สำหรับตรวจที่จอดรถ
- ทดสอบว่าผู้ใช้ต้องการ “จำนวนช่องว่าง”, “แนวโน้ม”, หรือ “ทางเลือกการเดินทาง” มากที่สุด

### ถ้า Map ไม่ได้ช่วยการตัดสินใจ
**Mode ถัดไป: Prototype**

- ลด Map ที่ไม่จำเป็น
- หรือเปลี่ยน Map ให้ตอบ task ที่ชัด เช่น จุดน้ำ/จุดจอดรถ/จุดเสี่ยง

### ถ้าผู้ใช้เสนอ Need ใหม่ที่ทีมไม่เคยพบ
**Mode ถัดไป: Empathize → Define**

- สัมภาษณ์เพิ่มเติม
- ตรวจสอบว่าเป็นปัญหาเฉพาะบุคคลหรือ pattern
- สร้าง/แก้ Need และ Insight
- พิจารณาแก้ POV/HMW ก่อนสร้าง solution ใหม่

## 3. Iteration loop

```text
Test with users
      ↓
Observe + Listen
      ↓
Feedback Matrix
      ↓
Find patterns
      ↓
Insight / Need
      ↓
Decide:
 ┌───────────────┬────────────────┐
 ↓               ↓                ↓
Prototype      Define           Empathize
 ↓               ↓                ↓
Re-test        Reframe POV       Learn more
 └───────────────┴────────────────┘
                ↓
               Test
```

# คำถามเพื่อทดสอบโปรเจคกับผู้ใช้งานเพื่อนำกลับไปแก้ไขเเละพัฒนาต่อไปมีดังนี้

# 1. ก่อนหน้าที่จะมาใช้แอปนี้ คุณเคยเจอปัญหาอะไรบ้างในการหาที่จอดรถหรือการวางแผนมาวิ่ง และปัญหานั้นส่งผลกระทบกับคุณอย่างไร?

# 2. ระดับความหนาแน่นที่แอปแสดงผลออกมา (เช่น การใช้สี ตัวเลข หรือเปอร์เซ็นต์) สื่อความหมายได้ชัดเจนและเข้าใจง่ายสำหรับคุณหรือไม่?“

# 3. ข้อมูลการแบ่งความหนาแน่นของคนและจุดจอดรถตามโซนต่างๆ มีส่วนช่วยในการตัดสินใจหรือช่วยให้คุณปรับเปลี่ยนแผนของคุณได้มากน้อยแค่ไหน?

# 4. ตัวเลขแสดงสถานะที่จอดรถบนแอปพลิเคชัน ตรงกับสภาพความเป็นจริงที่คุณไปถึงมากน้อยแค่ไหน?

# 5. เมื่อไปถึงสวน การใช้แผนที่ในแอปเพื่อค้นหาจุดกรอกน้ำ และการใช้ระบบคำนวณระยะทาง ช่วยในการวางแผนการวิ่งของคุณได้มากน้อยแค่ไหน?

# 6. หลังจากเริ่มใช้แอปพลิเคชันนี้ มีอะไรที่คุณรู้สึกว่าทำได้ง่ายขึ้น เร็วขึ้น หรือไม่ต้องกังวลเหมือนเมื่อก่อนบ้าง? (ขอให้เล่าจากประสบการณ์จริงสัก 1 เหตุการณ์)

# 7. หากสามารถปรับปรุงหรือเพิ่มฟีเจอร์ได้ 1 อย่าง เพื่อให้คุณอยากเปิดใช้แอปพลิเคชันนี้ทุกครั้งก่อนออกจากบ้าน คุณอยากให้เพิ่มอะไร หรืออยากให้มีข้อมูลอะไรเพิ่มเติมบ้าง?

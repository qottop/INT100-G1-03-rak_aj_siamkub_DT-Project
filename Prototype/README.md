# Thonburirom Smart Check

Prototype เว็บไซต์สำหรับ Design Thinking Week 5

## Concept

**Thonburirom Smart Check** ช่วยให้ผู้ใช้เช็กข้อมูลก่อนเข้าสวนธนบุรีรมย์ เช่น

- People Density
- Car Parking
- Recommended Time
- Water Station
- Prototype Map

## วิธีเปิดใช้งาน

ไม่ต้องติดตั้งอะไร

1. ดาวน์โหลด repository นี้
2. เปิดไฟล์ `index.html` ใน Chrome / Edge
3. ใช้ปุ่มบนหน้าเว็บเพื่อทดลอง Prototype

## หมายเหตุเรื่องข้อมูล

ข้อมูล **People Density, เวลาแนะนำ และจุด Water Station เป็นข้อมูลจำลองเพื่อสาธิต Prototype** ไม่ใช่ข้อมูล Real-time

Capacity ที่จอดรถยนต์ **20 คัน** ใช้เป็นข้อมูลอ้างอิงจากข้อมูลพื้นที่สาธารณะของกรุงเทพมหานคร
